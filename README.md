# MacGesture

GNOME Shell extension providing Mac-style touchpad gestures for **Ubuntu 26.04 / GNOME Shell 50 (Wayland)**.

- **3-finger horizontal swipe** — live app switcher with animated window clones
- **3-finger vertical swipe** — configurable (Overview, volume, brightness, maximize/minimize, etc.)
- **4-finger swipe** — configurable (workspace switching, volume, brightness, media, Alt+Tab, etc.)
- **3/4-finger tap** — configurable action

See [`macgesture@gurmeetgupta22/README.md`](macgesture@gurmeetgupta22/README.md) for full documentation, architecture, install instructions, and packaging.

## Quick install

```bash
bash install.sh
# Then log out and back in (Wayland), and:
gnome-extensions enable macgesture@gurmeetgupta22
```
